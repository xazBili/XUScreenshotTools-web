一个 Windows 截图工具

按 Win+Shift+S 框选，画完之后可以直接贴到桌面上。装着不用管它，托盘里常驻。

能干什么

  • 热键唤起Win+Shift+S，设置里可以换成别的键。
  • 标注矩形、箭头、画笔、马赛克、纯色遮挡、文字、序号。
  • 贴图截完钉在屏幕上对照着用，右键还能回到编辑。
  • OCR把画面里的字提出来，直接复制。
  • 翻译不用选源语言，译文可以直接盖在原图上。
  • 滚动截图长页面自动往下滚着拼。也有延时截图和窗口捕获。
  • 历史截过的图留在历史里，不用重截。
  • 皮肤与保存多套主题，保存路径和文件名规则自己定。

装上和卸掉

双击那个 exe，跟着走两步就完事了，不用管理员权限。选路径的时候它会自己建一层子文件夹，比如你把位置选到 D 盘，最后是 D:\XUScreenshotTools，文件不会跟别的混在一起。

卸载在开始菜单里，或者到安装目录双击 uninstall.exe。可以选择把设置一起清掉，也可以留着，下次重装还是原来的习惯。

设置、编辑器、历史这几个窗口是 WinUI 3 画的，需要系统里有 Windows App SDK 1.7 运行时，没有的话按提示装就行。截图按钮突然不好使的时候，先看看是不是别的软件把 Win+Shift+S 抢走了。
